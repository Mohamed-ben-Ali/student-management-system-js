# Student Management System

A beginner-friendly Student Management System built with JavaScript.

This project was created as part of my JavaScript learning journey to practice fundamental programming concepts through a practical example.

## Project Overview

The project manages a list of students and their grades using JavaScript.

It calculates student averages, determines pass/fail status, searches for students, and sorts students according to their academic performance.

## Concepts Practiced

### Phase 1: Loops & Conditions
- For loops
- Nested loops
- If / Else conditions
- Calculating grades and averages
- Counting successful and unsuccessful students

### Phase 2: Functions & Arrow Functions
- Function declarations
- Arrow functions
- Parameters and return values
- Reusable functions
- Searching for students by ID
- Handling invalid student IDs

### Phase 3: Array Methods
- forEach()
- map()
- filter()
- reduce()
- find()
- findIndex()
- some()
- every()
- sort()

## Features

- Display all student names and grades
- Calculate each student's average
- Determine successful and unsuccessful students
- Count successful and unsuccessful students
- Search for a student by ID
- Display student information
- Calculate the class average
- Find students by name
- Check conditions using some() and every()
- Sort students by average grade without modifying the original array

## Passing Criteria

A student is considered successful if their average grade is greater than or equal to 85.

## How to Run

Make sure Node.js is installed.

1. Clone this repository.
2. Open the project folder in your terminal.
3. Run:

```bash
node index.js
```

- JavaScript
- Node.js
